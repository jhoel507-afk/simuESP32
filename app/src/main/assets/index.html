      Funciones disponibles y límites del simulador
      
    
        
  • Librerías simuladas: Servo, DHT, LiquidCrystal_I2C, Adafruit_NeoPixel, Wire y WiFi (conecta siempre). También shiftOut para el 74HC595.
    • 
        
  • Lenguaje: C++ estilo Arduino (void setup(), int, float, String, #define, arreglos). También acepta JavaScript. No hay clases, struct ni librerías externas; la división entre enteros da decimales.
    • 
        
  • pinMode(pin, OUTPUT | INPUT | INPUT_PULLUP)
    • 
        
  • digitalWrite(pin, HIGH | LOW), digitalRead(pin)
    • 
        
  • analogRead(pin) (según la placa), analogReadResolution(bits)
    • 
        
  • analogWrite(pin, 0–255) (PWM)
    • 
        
  • delay(ms), millis()
    • 
        
  • Serial.println(x), Serial.print(x)
    • 
        
  • servoWrite(pin, ángulo)
    • 
        
  • pulseIn(echo, HIGH) → µs (cm = µs / 58.2)
    • 
        
  • dhtTemp(pin), dhtHum(pin)
    • 
        
  • Matemática y bits: sq, sin, cos, tan, log, exp, floor, ceil, round, radians, degrees, bitRead, bitWrite, lowByte, highByte
    • 
        
  • PWM de ESP32: ledcSetup, ledcAttachPin, ledcWrite (y ledcAttach); dacWrite, touchRead
    • 
        
  • tone(pin, Hz, ms), noTone(pin)
    • 
        
  • LCD: lcdClear(), lcdSetCursor(col, fila), lcdPrint(x)
    • 
        
  • OLED: oledClear(), oledPrint(fila 0–3, texto)
    • 
        
  • RTC: rtcHour(), rtcMinute(), rtcSecond(), rtcDay(), rtcMonth(), rtcYear(), rtcAdjust(a,m,d,h,mi,s)
    • 
        
  • MPU6050: mpuAccel() → {x, y, z} en g
    • 
        
  • map, constrain, random
    • 
      

      
Importante: SimuESP ejecuta una API educativa de estilo Arduino dentro del navegador; no compila ni carga firmware real en una placa física. El archivo de código descargado conserva el texto del editor para seguir trabajándolo.

Escribe setup() y loop() como en Arduino. Los cables unen cualquier pin con cualquier pin; todas las tierras (GND) de placa y fuentes se consideran unidas. Cada módulo debe recibir un voltaje dentro de su rango: si es bajo no funciona y si es alto se daña. Toca un pin para ver su voltaje.
